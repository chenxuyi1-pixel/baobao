# 抱抱她 🫂

> 安放你所有的情绪

专属于妈妈的多角色AI情感树洞——不是一个AI陪你聊，是你想找谁聊找谁聊。

---

## ✨ 项目简介

**抱抱她**是一款为妈妈群体打造的多角色AI情感陪伴应用。妈妈们在孕期、产后和日常生活中，常常有很多情绪无处安放——跟老公说嫌矫情，跟爸妈说怕担心，跟朋友说没人懂。

我们提供4个不同人设的AI角色，妈妈可以根据心情选"谁"来陪自己：

| 角色 | 人设 | 适用场景 |
|------|------|---------|
| 👶 小多米 | 10个月宝宝，奶声奶气的治愈杀招 | 情绪低落、心累、需要被治愈 |
| 💃 沈有才 | 路子野的闺蜜，吐槽功力一流 | 想吐槽、发泄、聊八卦、骂老公 |
| 👩 英姐 | 通透的过来人，有生活智慧 | 迷茫、需要过来人经验和建议 |
| 💼 陆景琛 | 霸道总裁，嘴硬心软护短 | 受委屈想被保护、想被人宠着 |

---

## 🛠 技术栈

- **前端框架**：Next.js 14+（App Router）
- **UI样式**：Tailwind CSS + shadcn/ui
- **部署**：Vercel
- **大模型**：豆包大模型（火山方舟）
- **语音合成**：豆包 TTS 2.0（4角色音色）
- **语音识别**：豆包 ASR 2.0（流式/单流）
- **存储**：localStorage（MVP阶段）

---

## 🎨 设计风格

**暖愈·糖素三合一**
- 底层：暖月治愈风（奶杏色渐变，温暖安心）

- 顶层：极简质感风（留白充足，线条干净）

## 🔒 伦理合规

1. 不诊断、不治疗——情感陪伴，不是心理咨询
2. 严重情况引导就医——识别到自伤倾向，引导寻求专业帮助
3. 不PUA、不控制——所有角色都是陪伴和支持
4. 隐私保护——MVP阶段数据存在本地，不上传
5. 亲人复刻有温度——不是消费悲伤，是给悲伤一个出口
