# 抱抱她 🫂

> 安放你所有的情绪

专属于妈妈的多角色AI情感树洞——不是一个AI陪你聊，是你想找谁聊找谁聊。

---

## ✨ 项目简介

**抱抱她**是一款为妈妈群体打造的多角色AI情感陪伴应用。妈妈们在孕期、产后和日常生活中，常常有很多情绪无处安放——跟老公说嫌矫情，跟爸妈说怕担心，跟朋友说没人懂。

我们提供4个不同人设的AI角色，妈妈可以根据心情选"谁"来陪自己：

| 角色 | 人设 | 适用场景 |
|------|------|----------|
| 🤍 就陪我说说 | 安静的倾听者，不说教 | 情绪很低、什么都不想解释的时候 |
| 👩 英姐 | 想象中的妈妈，会一直站在你旁边替你说话 | 迷茫、需要过来人的经验和建议 |
| 💃 沈有才 | 路子野的闺蜜，吐槽功力一流 | 想吐槽、发泄、聊八卦、骂老公 |
| 👶 小多米 | 5岁宝宝，奶声奶气的治愈杀招 | 情绪低落、心累、需要被治愈 |

---

## 🛡️ 安全分流机制

系统内置三级安全分流，保护每一位用户：

- **L1 高危自伤**：检测到自伤倾向，立即弹窗引导 12356 心理援助热线
- **L2 中度预警**：情绪低落相关表达，角色优先共情安抚，不输出刺激性内容
- **L3 日常陪伴**：正常情绪交流，角色按人设自然回应

---

## 🔧 技术栈

- **前端**：原生 HTML + CSS + JavaScript（零依赖、秒加载）
- **后端**：Vercel Serverless Functions
- **大模型**：豆包 doubao-seed-character-260628
- **语音合成**：豆包语音合成大模型 2.0（seed-tts-2.0）
- **前端语音兜底**：Web Speech API（浏览器原生）

---

## 📦 功能清单

- ✅ 4 个角色，独立人设和对话风格
- ✅ 真实大模型对话（豆包 API）
- ✅ 高质量 TTS 语音播报（豆包语音合成 2.0）
- ✅ 浏览器系统语音兜底（无网络也能听）
- ✅ 三级安全分流机制
- ✅ 对话上下文记忆（最近 6 轮）
- ✅ 响应式设计，手机端优先
- ✅ Mock 模式，无 API Key 也能演示
